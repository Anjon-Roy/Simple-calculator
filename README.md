 # Simple Calculator 🧮

A simple and beginner-friendly calculator built with Python.
This is my first Python project as a Mathematics student!

### ✨ Features
- Addition
- Subtraction
- Multiplication
- Division (with zero-division handling)

### 💻 How to Run
1. Clone the repo: `git clone https://github.com/Anjon-Roy/Simple-calculator.git`
2. Run: `python calculator.py`
